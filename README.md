# Expense-Tracker
## Автор: Зарубин Андрей
## Описание программы
Финансовый Трекер - это простое консольное приложение на Python, разработанное для отслеживания ваших личных доходов и расходов. Программа позволяет добавлять новые транзакции (доход или расход) с указанием суммы, категории и даты. Все введенные данные хранятся в файле transactions.json для сохранения между сессиями. Предусмотрена возможность просмотра всех записей, а также вывод суммарного баланса (доходы минус расходы).
## Как использовать
Запуск:
Сохраните предоставленный Python-код как файл с расширением .py (например, finance_tracker.py).
Запустите файл из командной строки: python finance_tracker.py.
Взаимодействие:
При запуске программа предложит вам выбрать одно из доступных действий:
1. Добавить транзакцию
2. Просмотреть все транзакции
3. Показать баланс
4. Выход
Введите соответствующую цифру и нажмите Enter.
Для добавления транзакции вам потребуется ввести ее тип (доход/расход), сумму (число), категорию (текст) и дату (в формате YYYY-MM-DD).

## Примеры использования

Добавить доход:
Выберите 1.
Введите доход.
Введите 50000 (сумма).
Введите Зарплата (категория).
Введите 2026-04-28 (дата).
Добавить расход:
Выберите 1.
Введите расход.
Введите 1200 (сумма).
Введите Продукты (категория).
Введите 2026-04-28 (дата).
Просмотреть все транзакции:
Выберите 2.
Будет выведен список всех добавленных транзакций.
Показать баланс:
Выберите 3.
Программа рассчитает и выведет общую сумму доходов и расходов, а также итоговый баланс.
